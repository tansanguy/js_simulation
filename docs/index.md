## 현재 원칙

- 이 문서 묶음이 현재 코드베이스와 정책의 기준이다.
- 이 문서 묶음은 `SUMO 1.26.0` 기준이다.
- `smoke`는 실행이 정상인지 확인하는 용도다.
- `final_summary.csv`가 최종 기준 파일이다.
- cut-off / graduation / PASS / CUT / KEEP / RECHECK 기준은 `docs/04_PIPELINE_POLICY.md`가 기준이다.
- paired comparison은 baseline-only가 아니라 baseline/smart pair가 함께 있는 결과로만 판단한다.
- 레거시 문서는 `oldresult/archived_20260518_docs_legacy/docs/` 아래에만 둔다.
- `SUMO_HOME`은 터미널을 새로 열 때마다 다시 설정한다.
